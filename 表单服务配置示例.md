# 表单服务配置示例

本文件提供三种主流表单服务的完整配置代码。

---

## 方案1: Formspree（最推荐）

### 优点
- 最简单，几乎零配置
- 免费版50次提交/月
- 自动发送到邮箱
- 有后台管理界面

### 配置步骤

1. 注册: https://formspree.io
2. 创建表单，获取ID（如: xabjklmn）
3. 在 index.html 找到这段代码（约第405行）:

```javascript
const response = await fetch('https://formspree.io/f/YOUR_FORM_ID', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(data)
});
```

4. 将 `YOUR_FORM_ID` 替换为你的表单ID

### 完整代码
```javascript
document.getElementById('inquiryForm').addEventListener('submit', async function(e) {
    e.preventDefault();
    
    const form = e.target;
    const formData = new FormData(form);
    const data = Object.fromEntries(formData.entries());
    
    try {
        const response = await fetch('https://formspree.io/f/xabjklmn', {  // 替换为你的ID
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: JSON.stringify(data)
        });
        
        if (response.ok) {
            document.getElementById('successMessage').classList.add('show');
            form.reset();
            
            setTimeout(() => {
                document.getElementById('successMessage').classList.remove('show');
            }, 5000);
        }
    } catch (error) {
        console.error('提交失败:', error);
        alert('提交失败，请稍后重试或直接联系我们。');
    }
});
```

## 方案2: EmailJS

### 优点
- 免费版200次发送/月
- 支持多种邮箱服务
- 可自定义邮件模板

### 配置步骤

1. 注册: https://www.emailjs.com
2. 连接邮箱服务（Gmail/Outlook等）
3. 创建邮件模板
4. 获取: Public Key, Service ID, Template ID

### 添加SDK
在 `</head>` 前添加:

```html
<script src="https://cdn.jsdelivr.net/npm/@emailjs/browser@3/dist/email.min.js"></script>
<script>
  (function(){
      emailjs.init("YOUR_PUBLIC_KEY"); // 替换为你的Public Key
  })();
</script>
```

### 完整代码
替换表单提交代码为:

```javascript
document.getElementById('inquiryForm').addEventListener('submit', function(e) {
    e.preventDefault();
    
    const form = e.target;
    
    // 发送邮件
    emailjs.sendForm('YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', form)
        .then(function() {
            document.getElementById('successMessage').classList.add('show');
            form.reset();
            
            setTimeout(() => {
                document.getElementById('successMessage').classList.remove('show');
            }, 5000);
        }, function(error) {
            console.error('发送失败:', error);
            alert('提交失败，请稍后重试。');
        });
});
```

### 邮件模板变量

在EmailJS模板中使用以下变量：
- {{company}} - 公司名称
- {{name}} - 联系人
- {{email}} - 邮箱
- {{phone}} - 电话
- {{product}} - 感兴趣的产品
- {{message}} - 详细需求

## 方案3: Web3Forms

### 优点
- 免费版250次/月
- 无广告
- 简单快速

### 配置步骤

1. 注册: https://web3forms.com
2. 获取Access Key

### 修改HTML表单
在 `<form>` 标签中添加:

```html
<form id="inquiryForm" action="https://api.web3forms.com/submit" method="POST">
    <!-- 添加Access Key -->
    <input type="hidden" name="access_key" value="YOUR_ACCESS_KEY">
    
    <!-- 其他表单字段保持不变 -->
    <div class="form-group">
        <label class="form-label" for="company">公司名称 *</label>
        <input type="text" id="company" name="company" class="form-input" required>
    </div>
    
    <!-- ... 其他字段 ... -->
</form>
```

### 完整代码（使用JavaScript）

```javascript
document.getElementById('inquiryForm').addEventListener('submit', async function(e) {
    e.preventDefault();
    
    const form = e.target;
    const formData = new FormData(form);
    
    try {
        const response = await fetch('https://api.web3forms.com/submit', {
            method: 'POST',
            body: formData
        });
        
        const result = await response.json();
        
        if (result.success) {
            document.getElementById('successMessage').classList.add('show');
            form.reset();
            
            setTimeout(() => {
                document.getElementById('successMessage').classList.remove('show');
            }, 5000);
        }
    } catch (error) {
        console.error('提交失败:', error);
        alert('提交失败，请稍后重试。');
    }
});
```

## 方案4: 自建后端（进阶）

如果你有服务器或想学习后端开发，可以自建表单处理接口。

### 使用Node.js + Nodemailer

1. 创建 `server.js`:

```javascript
const express = require('express');
const nodemailer = require('nodemailer');
const cors = require('cors');

const app = express();
app.use(cors());
app.use(express.json());

// 配置邮件发送
const transporter = nodemailer.createTransport({
    service: 'gmail',
    auth: {
        user: 'your-email@gmail.com',
        pass: 'your-app-password'
    }
});

// 接收表单提交
app.post('/api/inquiry', async (req, res) => {
    const { company, name, email, phone, product, message } = req.body;
    
    const mailOptions = {
        from: 'your-email@gmail.com',
        to: 'your-email@gmail.com',
        subject: `新询盘: ${company}`,
        html: `
            <h2>新的询盘信息</h2>
            <p><strong>公司:</strong> ${company}</p>
            <p><strong>联系人:</strong> ${name}</p>
            <p><strong>邮箱:</strong> ${email}</p>
            <p><strong>电话:</strong> ${phone}</p>
            <p><strong>感兴趣的产品:</strong> ${product}</p>
            <p><strong>需求:</strong> ${message}</p>
        `
    };
    
    try {
        await transporter.sendMail(mailOptions);
        res.json({ success: true });
    } catch (error) {
        res.status(500).json({ success: false, error: error.message });
    }
});

app.listen(3000, () => {
    console.log('Server running on port 3000');
});
```

2. 修改前端代码:

```javascript
const response = await fetch('http://your-server.com/api/inquiry', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(data)
});
```

## 高级配置

### 添加验证码（防止垃圾邮件）

使用Google reCAPTCHA:

1. 注册: https://www.google.com/recaptcha
2. 获取Site Key和Secret Key

在 `</head>` 前添加:
```html
<script src="https://www.google.com/recaptcha/api.js" async defer></script>
```

在表单提交按钮前添加:
```html
<div class="g-recaptcha" data-sitekey="YOUR_SITE_KEY"></div>
```

### 添加文件上传

如果需要用户上传文件（如产品需求文档）:

1. 使用Cloudinary或AWS S3
2. 修改表单添加文件输入:

```html
<input type="file" name="attachment" accept=".pdf,.doc,.docx">
```

### 多语言表单

为不同语言创建不同的表单ID，根据网页语言切换。

## 常见问题

**Q: 收不到邮件怎么办？**
- 检查垃圾邮件文件夹
- 确认配置正确
- 查看服务商后台是否有错误提示

**Q: 想要自动回复客户？**
- EmailJS支持自动回复
- 或使用后端方案发送两封邮件

**Q: 如何保存提交记录？**
- Formspree/EmailJS有后台管理
- 或连接Google Sheets（使用Zapier等）

**Q: 能否添加短信通知？**
- 可集成Twilio等服务
- 但需要付费和编程
