## ⚡ 3步上线（15分钟搞定）

### 1️⃣ 配置表单（5分钟）
1. 注册 Formspree: https://formspree.io
2. 创建新表单，获取表单ID
3. 在 `index.html` 第405行替换 `YOUR_FORM_ID`

### 2️⃣ 部署网站（5分钟）
1. 注册 GitHub: https://github.com
2. 创建新仓库，上传 `index.html`
3. 在仓库设置中启用 GitHub Pages

### 3️⃣ 自定义内容（5分钟）
1. 修改公司名称、标语
2. 更新产品/服务描述
3. 填写联系方式

**完成！** 你的网站已上线 🎉

详细步骤见 `部署指南.md`

## 🌐 推荐托管平台

| 平台 | 优点 | 缺点 |
|------|------|------|
| **GitHub Pages** | 完全免费，稳定 | 国内访问稍慢 |

## ⚠️ 重要提示

1. **必须替换表单ID** - 否则表单无法工作
2. **修改联系信息** - 否则客户联系不到你
3. **启用HTTPS** - 所有平台都自动支持
4. **定期备份** - 保存一份本地副本

## 🆘 遇到问题？

### 表单不工作
- 检查是否替换了 `YOUR_FORM_ID`
- 查看浏览器控制台的错误信息
- 确认Formspree账号已激活

### 网站打不开
- 等待5-10分钟（DNS生效需要时间）
- 清除浏览器缓存
- 检查GitHub Pages是否已启用

### 样式显示异常
- 确保上传了完整的 `index.html`
- 使用Chrome/Edge等现代浏览器
- 检查文件编码是否为UTF-8
